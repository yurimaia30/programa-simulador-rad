# Radiografias do módulo Neonatal

O módulo já está preparado para receber duas imagens. Quando estiverem disponíveis, adicione nesta pasta os arquivos:

- `neonatal_torax_abdomen.jpg`: Tórax e Abdômen AP no leito.
- `neonatal_perfil.jpg`: Perfil horizontal / decúbito.

Use os nomes exatamente como acima, em minúsculas, com imagens no formato JPEG. Depois publique os arquivos junto com o site. Não é necessário alterar o código ou recriar o banco.

Enquanto as imagens não forem adicionadas, a estação informa que serão disponibilizadas em breve e impede o envio de um exame sem imagem. O módulo continua identificado como Brinde e depende de liberação pelo professor.
